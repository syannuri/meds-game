Kebijakan Privasi Rel Nusantara

Berlaku sejak 5 November 2026

Ringkasan

Rel Nusantara adalah game simulasi masinis kereta yang dimainkan sepenuhnya di perangkat Anda. Game ini tidak mengumpulkan, tidak mengirim, dan tidak membagikan data pribadi apa pun.

Data yang disimpan

  • Kemajuan permainan (bintang, misi selesai, kartu pos, skor harian) dan pengaturan (musik, suara, tampilan kabin, livery) disimpan hanya di perangkat Anda menggunakan penyimpanan lokal aplikasi.
  • Data ini tidak dikirim ke server mana pun dan akan terhapus bila aplikasi dihapus atau data aplikasi dibersihkan.

Yang tidak kami lakukan

  • Tidak ada akun, login, atau pendaftaran.
  • Tidak ada iklan, analitik, pelacakan, atau SDK pihak ketiga.
  • Tidak meminta akses kamera, mikrofon, lokasi, kontak, atau file.
  • Tidak ada pembelian dalam aplikasi.

Izin aplikasi

Versi Android tidak meminta izin apa pun, termasuk izin Internet. Semua gambar, suara, dan huruf game sudah ada di dalam aplikasi sehingga game dapat dimainkan tanpa koneksi.

Anak-anak

Game ini cocok untuk semua umur dan tidak mengumpulkan data dari anak-anak maupun pengguna lain.

Perubahan kebijakan

Bila kebijakan ini berubah, versi terbaru akan dimuat di halaman ini beserta tanggal berlakunya.

Kontak

Rel Nusantara dikembangkan oleh Prismatix Lab. Pertanyaan tentang privasi dapat dikirim ke alamat email pengembang yang tercantum di halaman Rel Nusantara di Google Play.
